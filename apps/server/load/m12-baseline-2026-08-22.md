# M12 Tooling readiness baseline — 2026-08-22

This local deterministic readiness baseline runs the real Express Tooling boundary, Better Auth OAuth device/token flow, shared Effect runtime, PostgreSQL repositories, signed cursors, authorization, rate limits, schema integrity verification, serialization, and cache handling through Supertest. It is a regression/readiness measurement, not a production-capacity claim.

## Representative fixture

- One OAuth user with current project membership
- Two discoverable projects and their `main` environments
- CMS enabled for the primary project
- Two published collections
- One localized required field and one immutable schema revision per collection
- Manifest page size `1`, forcing a signed continuation cursor
- Alternating authenticated first-page manifest and immutable revision reads
- Tooling response ceiling: 1,572,864 bytes
- Repository statement timeout: 750 ms
